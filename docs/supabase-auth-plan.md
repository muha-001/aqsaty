# تسجيل دخول Supabase والمزامنة — خطة تنفيذ

**الهدف:** تمكين المستخدم من تسجيل الدخول إلى Supabase من لوحة الإدارة وتشغيل المزامنة السحابية بعد نجاح المصادقة.

**المعمارية:** تبقى IndexedDB المصدر المحلي الفوري، وتستخدم طبقة `cloudSync.ts` عميل Supabase واحدًا لإدارة الجلسة ورفع/سحب قاعدة البيانات. تعرض لوحة الإدارة بطاقة مصادقة مستقلة مع حالة واضحة، وبعد تسجيل الدخول يعاد سحب السجل السحابي.

**الملفات:**
- تعديل `src/domain/cloudSync.ts` لإضافة تسجيل الدخول والخروج وجلب الجلسة.
- تعديل `src/App.tsx` لإضافة بطاقة مصادقة داخل النسخ والإعدادات وإعادة سحب البيانات بعد نجاح الدخول.
- تعديل `src/styles.css` لتنسيق حالة المزامنة.
- تحديث `README.md` بخطوات الاستخدام.

**التحقق:** `npm run check`، `npm run build`، وفحص `git diff --check` وعدم تضمين `.env.local`.
