# Guarantors and Guarantees Implementation Plan

**Goal:** إضافة نظام ضامنين وكفلاء مرتبط بالعقود، مع بيانات الاتصال والعنوان والعلاقة ومستندات الضمان وتذكير الضامن عند التأخر.

**Architecture:** أضيفت كيانات الضامنين إلى قاعدة البيانات المحلية والسحابة داخل حمولة `aqsaty_records` الحالية بصيغة JSONB، مع ربط العقود عبر `guarantorIds` و`requiresGuarantee`. تحفظ مستندات الضمان مع نوعها واسمها ونوع MIME وحجمها وبياناتها المحلية، وتُفتح رسالة WhatsApp إلى هاتف الضامن فقط بعد ضغط المستخدم على زر التذكير.

**Implementation:**

- تعريف `Guarantor` و`GuaranteeDocument` وأنواع المستندات، مع ترحيل آمن للبيانات القديمة.
- التحقق من الاسم والهاتف العراقي والعلاقة والعنوان وبيانات المستند.
- ربط ضامن جديد أو ضامن موجود بالعقد ومنع تكرار الرابط.
- لوحة إدارة عربية RTL تعرض بيانات الضامنين، المستندات، العقود المرتبطة، والحذف مع تأكيد.
- زر تذكير يظهر للعقود المتأخرة ويبني رسالة باسم الضامن ورقم العقد وإجمالي المتأخرات وتفاصيل الأقساط.
- دمج الضامنين في `mergeCloudDatabases` حتى لا تضيع سجلاتهم عند المزامنة.
- عدم إضافة migration منفصل لأن `aqsaty_records.payload` الحالي يخزن قاعدة البيانات كاملة بصيغة JSONB، وتتم مزامنته عبر مسار Supabase الموجود.

- `npm run build` ناجح.
