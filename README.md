# aqsaty

نظام عربي RTL لإدارة الأقساط محليًا، مبني بواجهة **React + TypeScript + Vite** ومجهز للنشر على GitHub Pages.

## المبدأ التشغيلي

المشروع لا يستخدم خادمًا أو قاعدة بيانات سحابية أو اشتراكًا خارجيًا. تحفظ بيانات الزبائن والعقود والدفعات داخل **IndexedDB** في متصفح جهاز الإدارة، مع ترحيل تلقائي للبيانات القديمة من `localStorage` عند التحديث. يمكن تصدير نسخة احتياطية مشفّرة بصيغة JSON وحفظها يدويًا على USB أو جهاز موثوق.

> التخزين دائم داخل جهاز الإدارة وليس بين عدة أجهزة. حذف بيانات المتصفح أو فقدان الجهاز قد يؤدي إلى فقدان البيانات؛ لذلك يجب أخذ نسخة احتياطية مشفّرة دوريًا.

## تشغيل المشروع

```bash
npm install
npm run dev
```

## فحص وبناء نسخة الإنتاج

```bash
npm run check
npm run build
```

تُنتج نسخة الإنتاج داخل مجلد `dist`.

## النشر على GitHub Pages

يحتوي المشروع على Workflow داخل `.github/workflows/deploy-pages.yml` يبني المشروع وينشر مجلد `dist` تلقائيًا عند كل Push إلى فرع `main`.

من إعدادات المستودع، اختر:

```text
Settings → Pages → Source: GitHub Actions
```

## الهيكلية

```text
src/
├── components/
│   └── ContractCard.tsx     # بطاقة العقد وجدول الأقساط
├── domain/
│   ├── seed.ts              # البيانات التجريبية الأولية
│   ├── store.ts             # IndexedDB وlocalStorage الانتقالي والحسابات
│   └── types.ts             # نماذج البيانات TypeScript
├── App.tsx                  # تركيب الواجهات وإدارة حالة التطبيق
├── main.tsx                 # نقطة دخول React
├── styles.css               # نظام التصميم RTL المتجاوب والحركة
└── vite-env.d.ts            # تعريفات Vite
```

## الوظائف الحالية

- إدارة الزبائن والعقود المتعددة لكل زبون.
- إنشاء جدول 6 أو 10 أو 12 شهرًا مع معالجة فرق التقريب في القسط الأخير.
- تسجيل دفعات نقدية أو تحويل أو بطاقة.
- حساب المسدد والمتبقي والمتأخرات.
- كشف العميل عبر رقم الهاتف.
- تذكير القسط عبر WhatsApp برسالة جاهزة وبإرسال يدوي.
- إدارة المنتجات والمخزون والأرقام التسلسلية والصور.
- تخزين دائم محلي داخل IndexedDB مع ترحيل تلقائي من localStorage.
- تغيير كلمة مرور الإدارة من لوحة النسخ والإعدادات.
- حفظ كلمة المرور كقيمة مجزأة باستخدام PBKDF2 بدل تخزينها كنص واضح.
- تصدير واستيراد النسخ الاحتياطية المشفّرة.
- واجهة عربية متجاوبة مع الهاتف.
- حركة واجهة خفيفة مع دعم `prefers-reduced-motion`.

## تغيير كلمة المرور

بعد الدخول إلى لوحة الإدارة، افتح **النسخ والإعدادات**، ثم أدخل كلمة المرور الجديدة واضغط **حفظ كلمة المرور**. التغيير محلي على نفس المتصفح والجهاز، ولا ينتقل إلى جهاز آخر.

## ملاحظة الخصوصية

لا ترفع ملفات النسخ الاحتياطية إلى GitHub لأنها قد تحتوي على أرقام هواتف وبيانات مالية. كلمة مرور الإدارة محلية داخل الجهاز وليست نظام مصادقة لخادم. إذا كان المطلوب تشغيل النظام من عدة أجهزة أو منح صلاحيات متعددة للموظفين، فستحتاج النسخة المستقبلية إلى خادم وقاعدة بيانات — وهو خارج نطاق التخزين المحلي الحالي.
